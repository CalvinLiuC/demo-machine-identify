# Kinematic Lab · 工业场景运动学 Demo

使用 **TypeScript + Three.js + Vite** 的浏览器工作台，演示从静态三维场景建立设备、连杆、运动副和外部装配，再导出 URDF 的半自动流程。所有文件在本地浏览器处理，不使用云端 AI 或动力学引擎。

## 启动

需要 Node.js **24.12+**（脚本和测试使用 Node 原生 TypeScript 支持）。

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认 `http://127.0.0.1:5173`。如果环境限制系统 npm 缓存目录，使用 `npm ci --cache .npm-cache`。

```sh
npm run typecheck
npm test
npm run build
npm run test:e2e
```

浏览器测试默认使用 Windows 已安装的 Chrome。其他系统设置 `CHROME_PATH` 为 Chrome/Chromium 可执行文件路径；不要求额外下载浏览器。`npm run build` 生成可静态部署的 `dist/`；需通过 HTTP 提供，不能直接双击 HTML。

## 已实现

- 内置导轨、六轴串联机器人、双指平行夹爪，共 3 个设备、8 个独立自由度。
- 刚体正运动学、旋转/移动/固定关节、跨设备固定安装、线性 mimic 联动。
- 本地 GLB 导入：节点实例累计变换、Y-up/Z-up 转换、米/毫米/厘米尺度、材质组分区。
- 本地 ASCII / 二进制 STL 导入：保留 ASCII solid 几何分区，支持尺度与上方向转换，并接入分组、关节编辑和 URDF 导出。
- 单体 STL 自动预处理：在 Web Worker 中解析、拆分连通分量、记录源三角面范围、提取局部端面并生成串联机构和静态结构候选。
- 主体邻接路径、小件表面距离归属、竞争归属标记、单侧/双侧轴线证据、候选应用与撤销；没有证据的运动副保持未解析。
- 支持普通、Meshopt 和 Draco 压缩的静态网格；Draco 解码器随构建打包到本地资源，不依赖 CDN。
- 设备/link 着色、射线选择、Ctrl/Shift 多选、线框、轴向箭头、镜头适配。
- 常驻识别结果面板：设备类别、几何/link 数量、R/P 数量、待应用/待确认状态与连杆展开；点击设备或连杆即可选择，⌖ 按钮定位。
- 选中对象以青色填充、亮轮廓和包围框显示，其他模型淡化；顶部显示选中名称，支持「定位选中」「仅显示选中」「清除选择」、空白处单击或 Esc 清除。
- 人工创建设备与 link、重新分配网格、选择父连杆、编辑原点与轴、设置演示范围和联动。
- 网格连通分量拆分；包围盒结构候选；PCA 主轴及近完整圆柱轴线拟合与应用。
- 有限范围的直线导轨几何模板匹配：双平行轮廓、支撑体与唯一滑台共同满足条件时，给出可确认的设备/link/P 关节分组候选。
- P、6R、双 P 联动和静态构型的拓扑检查。
- 逐轴与自动演示、参考姿态恢复、循环/非法安装检查、参考姿态重建误差及安装点一致性检查。
- 撤销结构编辑、项目 JSON 保存/恢复、静态 GLB 测试样本下载。
- ZIP 导出：独立设备 URDF、整体 URDF、link 局部 STL、装配描述、初始/预览状态及可重新打开的项目。

## 操作流程

### 首选：一个 STL 包含整个场景

1. 根据源文件选择尺度和上方向，再导入 STL。解析与分析在后台运行，有进度提示。
2. 系统自动从单个 solid 中拆分几何连通分量，无需事先用 CAD 拆件。
3. 点击「查看识别候选」，审阅串联机构、静态结构组、未归属几何，以及每个关节的几何依据。
4. 「查看分组」可高亮候选 link；「选择竞争归属几何」定位需要重点核验的小件。
5. 点击「应用设备 / 连杆 / 关节候选」，按 link 着色查看自动分组，逐轴小幅预览。应用会替换当前机构结构，可撤销。
6. 修正小件归属、父子顺序和轴线，在右侧确认。轴线候选中同时提供局部圆形端面备选。
7. 导出装配包或保存项目。导出同样在后台执行，局部网格使用二进制 STL，降低大模型导出的内存开销。

「自动拆分与机构分析」也能用于已导入的 GLB 场景。重新分析只生成候选，点击应用前不会替换已编辑的运动链。

实际回归模型包括约 80 MB、305,044 个三角面的 `model.stl`，以及约 95 MB、1,208 个连通分量的 `model2.stl`。后者重建为六轴机器人候选、独立末端夹爪候选和单轴变位机候选，保留静态结构及未归属几何。末轴由重复紧固件孔阵列、腕部几何和 6R 模板推断，采用无独立可视网格的法兰输出 link。**这些是可审阅候选，不代表通过了厂商参数或独立多姿态标定**。

开发者可针对这份本地模型执行附加回归；模型不需要放入 Git：

```powershell
$env:REAL_STL_PATH = 'D:\models\model.stl'
$env:REAL_STL_2_PATH = 'D:\models\model2.stl'
npm test
npm run test:e2e
```

此附加用例对应上述已检查的具体模型。未设置变量时跳过，通用合成模型测试仍正常执行。

### 先体验已知机构

1. 启动后即显示完整示例，拖动 `carriage` 验证整机随滑台运动。
2. 拖动机器人各轴，确认只有下游连杆随动。
3. 拖动 `finger_left`，观察另一指爪按相反空间方向联动。
4. 点击「验证模型」检查参考姿态、安装关系和构型模板。
5. 点击「导出装配包」。

示例由预定义机构生成，**不代表系统从任意模型自动识别出了完整设备**。

### 使用自己的 GLB / STL

1. 选择源尺度和上方向，再导入 GLB 或 STL。GLB 应自包含，不依赖外部纹理或 buffer。STL 不保存可靠单位或上方向，必须根据源模型选择；例如毫米、Z-up 的 STL 选择「毫米 · ×0.001」和「Z-up」。
2. 导入几何暂存为一个「未分类设备」，不信任节点名称和层级。STL 在后台自动拆分并分析；若需手工调整，也可以使用「分离选中网格的连通分量」。STL 顶点颜色暂不保留。
3. 点击「几何候选分析」查看尺寸与长条结构候选。若满足有限导轨模板，会提供固定体/滑台分组及 P 关节候选；点击确认后建立候选设备，仍需验证运动关系。
4. 在视图或几何列表选择某设备的网格，点击「从选择建立设备」，指定预期构型。
5. 选择一个刚体的几何，在正确的父 link 下点击「从选择建立连杆」。重复建立机构。
6. 在右侧编辑 R/P/固定关节、参考原点、关节轴和父 link。可使用「拟合选中几何的轴线候选」辅助定位。
7. 对夹爪等机构设置联动源、倍数及偏置；多级 mimic 和非线性闭链暂不支持。
8. 对外部安装，选择子设备根 link，将父连杆设为宿主的滑台/法兰 link，保持固定关节。
9. 逐轴预览，确认正确后勾选确认，保存项目并导出。

移走暂存几何后，空的暂存设备仍保留为固定参考节点，不影响运动计算。当前没有任意面片手绘分割；一个连续合并外壳若没有可分离的连通分量，需先在三维建模工具中拆分。

### 无模型时测试导入

「几何候选分析 → 下载无运动学 GLB 测试样本」可下载当前参考几何。它删除语义名称且不含运动学标注。重新导入后，应回到未分类状态，用于演示人工重建流程。

## 坐标与运动学约定

- 内部单位：米、弧度；右手 Z-up。UI 运动读数显示度和毫米。
- 每个 link 保存导入参考姿态下的世界变换 `bind`。
- 网格在内存中使用规范化参考世界坐标；显示时施加 `currentWorld × inverse(bind)`。
- 子 link 当前位姿为 `parentCurrent × inverse(parentBind) × childBind × jointMotion(q)`。
- 导入姿态定义为建模零位；零状态重建输入几何，不推断厂商机械零位或编码器偏置。
- 关节轴在 link/joint 的参考坐标中表达。UI 创建的参考坐标系默认世界对齐，关节轴可以是任意方向。
- 导出网格执行 `inverse(bind)`，得到 link 局部网格。独立设备根坐标位于该设备根 link，外部安装位姿由 `assembly.json` 给出。
- 安装关系当前使用设备根/宿主 link 作为接口；没有单独的孔阵列接口检测和自动配合求解。
- 线性联动为 `q_follower = multiplier × q_source + offset`，轴向决定实际空间运动方向。

## 导出目录

```text
kinematic-assembly.zip
├── devices/{device_id}.urdf
├── meshes/{link_id}.stl
├── scene.urdf
├── assembly.json
├── project.json
├── recognition.json           # 自动分析存在时输出
├── package.xml
├── CMakeLists.txt
└── README.txt
```

网格引用使用 `package://kinematic_scene_demo/meshes/...`。导出目录可作为 ROS 2 `ament_cmake` 资源包放入工作空间，通过 `colcon build` 安装并 source 环境。独立加载器需为 `kinematic_scene_demo` 配置包路径。没有在本环境运行 ROS/RViz 验证。

`assembly.json` 包含父设备、宿主 link、设备根、安装变换、确认状态、初始零状态与 UI 预览状态。矩阵为 Three.js/glTF 风格列主序数组；`installationTransform` 将子设备根坐标映射到父 link 坐标。恢复时设置零初始状态可还原导入场景；应用预览状态时，mimic 关节由其源关节求值。

URDF 不包含惯性、碰撞和驱动。所有运动范围均为 **演示值**，`effort=1`、`velocity=1` 只是 URDF 兼容占位，**不能用于真实设备控制**。几何导出为二进制 STL，不保留纹理；项目 JSON 保留三角网格和基础颜色。`recognition.json` 包含候选分组、端面证据、轴线备选、竞争归属和未知项。

## 自动化边界

本版提供单体 STL 的串联机器人候选重建、末端夹爪分离、单轴/双轴变位机和有限导轨匹配，尚未完成任意机构的通用识别。串联重建寻找主体邻接链并合并重复同轴薄盖，避免把轴承盖计为额外关节。腕部缺少独立旋转壳体时，可从重复紧固件的共面圆阵列及腕部模板推断末轴，必须记录这一来源和几何偏差；不直接把末端工具当作机器人连杆。

夹爪按独立设备挂接到机器人输出法兰候选。双侧构件仅凭外形不能确定平移/转动或联动时，保持 `unresolved`、暂固定显示，不能理解为其真实固定。变位机使用圆盘工作面、厚支撑壳体与同轴接口判定；双轴模板进一步要求支架/倾转架接口和两个近正交回转副，提供 1R/2R 模板和运动链。双轴已用合成构型测试，尚未用用户提供的真实双轴型号验证。

算法版本保存在 `analysis.algorithmVersion`，每次分析具有独立 revision。重新分析后即使候选设备 ID 相同，也显示为「尚未应用」；已保存旧版结果提示重新分析，不静默替换用户模型。

- 长宽比只提供长条候选，不能把横梁判断为导轨。
- 圆柱拟合只验证几何形状，不证明它是转轴；当前使用协方差候选方向和投影圆拟合，不是抗严重遮挡的 RANSAC。
- 局部端面结合平面桶和三角面邻接聚合，再进行边界、投影圆和角覆盖检测，减少倾斜端面被 STL 坐标舍入拆散的问题。法兰孔阵列使用重复件中心的共面圆拟合与异常点剔除。同轴几何仍不能证明真实运动副。
- 竞争归属的小件和重复同轴薄盖不再强行分给最近连杆，保留待分配；因此新版本的未归属数量可能增加。
- 变位机检测优先支持场景中尺寸显著、工作面可见的回转台，使用相对场景尺度的最小半径阈值；小型、遮挡、外形非圆、驱动完全隐藏的机构可能需要人工模板。没有把所有圆盘都判为变位机。
- 连通分量不等于独立零件，也不等于刚体 link；拆分仅使用约 `1e-6 m` 的顶点位置量化邻接。
- 若布尔融合、共享顶点或网格简化已消除运动部件边界，自动拆分可能只能得到一个连通体。本版会提示并保留未知，不执行任意曲面切割，也不虚构运动链。
- 根 link 和串联顺序是几何假设；基座选择依赖用户指定的 Z-up。静态结构采用较宽邻接阈值聚合，可能包含多个静态设备；空间接近不能证明安装关系。
- 机构间安装关系不会自动设为固定；各设备先保留在世界参考系，需人工确认安装宿主。
- 参考姿态和安装点一致性是内部自洽检查，不是独立运动学真值验证。
- 不支持蒙皮、柔性件、复杂闭链、逆运动学、碰撞规划或动力学。
- 已使用 Web Worker 与 TypedArray 转移，实际验证约 30 万三角面；没有流式解析或百万零件性能保证。较大模型保存 JSON 时仍可能短暂占用主线程。
- 目前确认状态以 link 为单位；没有完整的参数级概率校准或多候选管理。

下一步可围绕有真值测试集，增加型号库配准、局部解析面 RANSAC、安装孔阵列匹配、多姿态辨识和面片交互分割；不应先扩大“全自动恢复”的宣称。

## 源码结构

| 模块 | 职责 |
| --- | --- |
| `src/types.ts` | 设备、几何、link、joint、项目数据类型 |

| `src/geometry.ts` | PCA、圆柱轴候选拟合 |
| `src/templates.ts` | 构型定义与拓扑检查 |
| `src/rail-template.ts` | 有限导轨几何模板匹配与证据 |

| `src/topology.ts` | TypedArray 并查集、保留源面范围的自动拆分 |
| `src/surface-features.ts` | 局部端面、平面占比、近似/低面数精确表面距离 |
| `src/planar-regions.ts` | 舍入噪声下的邻接平面三角面聚合 |
| `src/interface-patterns.ts` | 法兰孔阵列、同轴约束和腕部几何校验 |
| `src/device-matchers.ts` | 单/双轴变位机及独立末端夹爪候选 |
| `src/scene-analysis.ts` | 串联候选路径、腕部延伸、小件归属、候选应用 |
| `src/scene-worker.ts`、`src/processing-client.ts` | 后台导入、分析、导出与进度 |
| `src/project-transfer.ts` | TypedArray 传输与共享不可变几何的撤销快照 |
| `src/recognition-ui.ts` | 设备/link/轴线候选与证据审阅 |
| `src/export.ts` | URDF、局部网格、装配与项目序列化 |
| `src/demo.ts` | 已知模板测试场景 |
| `src/viewer.ts` | Three.js 渲染、选择、轴线与相机 |
| `src/main.ts` | 工作台交互 |
| `tests/`、`e2e/` | 运动学/导出测试、Chrome 端到端测试 |
